## 1. Project Overview

**Noorisys Healthcare** is a world-class, premium, dark futuristic healthcare technology portfolio website showcasing 15 specialized digital healthcare products. It positions Noorisys Technologies as an established engineering partner with a deep, multifaceted healthcare product ecosystem.

- **Hero Headline:** The Future of Healthcare Is Connected.
- **Core Tagline:** Healthcare Technology. Beyond Boundaries.
- **Supporting Statement:** Explore a portfolio of specialized healthcare products designed to advance digital healthcare experiences, empower healthcare professionals and simplify healthcare operations.

## 3. Technology Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript (Strict mode)
- **Styling:** Tailwind CSS + Custom CSS Variables & Animations
- **3D Visualization:** Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Forms & Validation:** React Hook Form, Zod, `@hookform/resolvers`
- **Typography:** Manrope (Headings), Inter (Body)
- **Deployment:** Vercel / Node.js / Docker ready

---

## 4. Key Design & Architectural Highlights

1. **Brand Fidelity:** Strictly preserves parent company identity (**Noorisys Technologies Pvt. Ltd.**, est. 2011) with verified contact details (`sales@noorisys.com`, `+91 77966 14664`).
2. **Interactive 3D Ecosystem:** React Three Fiber 3D Canvas featuring a central glowing digital healthcare core, orbiting stakeholder nodes (Patients, Doctors, Hospitals, Labs, Pharmacies, Emergency), animated connection lines, particle field, and mouse parallax—with automatic WebGL detection and low-power fallback.
3. **Filterable 15-Product Showcase:** Live search with instant filtering across all 7 medical domains.
4. **Interactive Ecosystem & Domain Showcases:** Visualizing clinical coverage without making unsubstantiated interoperability claims.
5. **Dynamic Product Detail Pages:** Dedicated routes (`/products/[slug]`) for every innovation with features, stakeholders, architecture highlights, and direct platform links.
6. **Validated Enterprise Enquiry Form:** Zod + React Hook Form with honeypot anti-spam protection and server-side processing.
7. **SEO Optimization:** Dynamic XML sitemap, `robots.txt`, OpenGraph metadata, and semantic markup.

## 5. Development & Build Instructions

### Prerequisites
- Node.js 18+ (tested on v24.22.1)
- npm 9+

### Setup & Run
```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Start production server
npm run start
```
